
Nombre del Proyecto:
Triple Espresso

Descripcion del Proyecto y su funcionalidad:
 Triple Espreso es una landing page de una caferira, tiene como objetivo presentar o hacer visible la cafeteria en la web, y captar reservas con el formulario. 

su funcionalida es principal mente enfocada en tres factores
-Presentar el negocio.
-Por medio de un formulario captar reservas.
-por medio de footer reedirigir a los usuarios a las redes siciales del proyecto.

Descripcion de las tecnologias y tecnicas usadas 
 
 - HTML como la estructura de la pagina.
 - CSS para la apariencia de la pagina .
 - normaliza.css se usa como base para la estandarizacion del CSS independientemete del navegador de internet.
 - Google fonts se usa para abquirir los fondos desde un servidor externo . 
 -svg para todas las imagenes,fondos, logotipos y iconos.
 -pretier para dar formato consistente al la pagina.
 -github para gestionar versiones.

 tecnicas utilizadas:
 -html el uso debido de etiquetas y clases para toda su maquetacion.
 -css , flexbox, grid, posicionamiento.
 -html en formulario , uso de las labels, y inputs debidamente y su botton , casilla de verificacion con checkbox y personalizada con CSS. uso del placeholder para guiar al usario sobre los campos.
